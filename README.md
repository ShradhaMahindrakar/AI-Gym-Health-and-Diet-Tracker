# AI Gym Health & Diet Tracker

Your ultimate, intelligent personal trainer and nutritionist built into one seamless application. The AI Gym Tracker provides tailored fitness plans, AI-generated diet strategies, comprehensive streamed workout plans, and interactive health quizzes. It leverages the advanced capabilities of the Google Gemini model to deliver professional guidance instantly.

## 🚀 Services & Features

1. **AI-Generated Fitness Plans**
   - Skip the generic advice. Get highly individualized workout routines based on your specific body type, goals, available time, and resources.
   - The AI engine generates progressive regimens to ensure you are continually challenged.

2. **Smart Diet & Nutrition Guides**
   - Request customized meal plans, macro-nutrient breakdowns, and detailed dietary guidelines that pair perfectly with your fitness goals (e.g. cutting, bulking, or maintaining).

3. **Streamed Workout Content**
   - Experience dynamic, streamed workout steps generated on-the-fly, allowing you to follow along with varied techniques and instructions as they are created. 

4. **Interactive Health Quizzes**
   - Test your knowledge on recovery, nutrition, and fitness science with quizzes generated by the AI, keeping your health literacy sharp.

## 💻 Tech Stack

- **Client**: React 19 + Vite. Designed with a robust, modern UI utilizing `lucide-react` icons and `react-markdown`.
- **Server**: Bun runtime running Express.js for lightning-fast and lightweight backend API services.
- **AI Integration**: Vercel AI SDK (`ai` package) with the `@ai-sdk/google` provider to bridge seamlessly with Google Gemini.
- **Database**: Local `bun:sqlite` database managing history, user-generated routines, and quiz scores reliably with low-latency WAL configuration.

## 🛠️ Setup and Installation

### Prerequisites
- Node.js & npm
- Bun
- Google Gemini API Key

### Getting Started

1. Clone or navigate into the directory:
   ```bash
   cd ai-gym-tracker
   ```

2. Install all dependencies recursively (client & server variables):
   ```bash
   npm run install:all
   ```

3. Configure your API key via `.env`:
   Navigate to the `server/` directory, create your `.env` file, and securely insert your keys.
   ```bash
   cd server
   # Create a file named .env and paste your API key inside:
   ```
   *`.env` contents*:
   ```env
   GOOGLE_GENERATIVE_AI_API_KEY=your_api_key_here
   ```

## 🎯 Running the App

### Development Setup

Start both the client and server instantly using `concurrently`. By running this from the root directory, your React application and your Bun server will spin up together hooked via proxy.

```bash
npm run dev
```

- **Frontend Application**: Connects to `http://localhost:5173`
- **Backend API Server**: Runs on `http://localhost:3001`

### Production Build

```bash
npm run build
npm start
```
This builds your React frontend into the static `client/dist` folder and spins up the Express server directly via Bun. The server handles routing and serves static files concurrently with your API endpoints.
